Buku Panduan Penggunaan Examify PDF

⚠️ KEBIJAKAN PENGHAPUSAN DATA 7 HARI

Untuk menjaga agar aplikasi tetap ringan dan stabil, sistem akan menghapus data nilai siswa secara otomatis dalam waktu 7 hari sejak jawaban dikirim.
Peringatan: Data yang sudah terhapus tidak dapat di-Undo (dikembalikan). Oleh karena itu, sangat diwajibkan bagi Guru untuk segera menekan tombol ⬇ Unduh Excel setelah ujian selesai dilaksanakan.

1. Format Pembuatan Kunci Jawaban

Agar sistem dapat mengoreksi otomatis dengan akurat 100%, ikuti panduan pengisian kunci berikut berdasarkan tipe soal:

  • Pilihan Ganda Biasa & Benar/Salah: Cukup klik opsi yang benar pada tombol yang disediakan.
  • Pilihan Ganda Kompleks: Klik 2 atau lebih opsi jawaban yang benar.
  • Menjodohkan: Ketikkan pasangan angka dan huruf. Anda boleh memisahkannya dengan koma atau spasi (Misal: 1A, 2B, 3C atau 1A 2B 3C). Sistem kami secara cerdas akan membersihkan dan mengurutkannya secara otomatis menjadi format 1A2B3C.
  • Isian Singkat: Ketik jawaban pasti (Sama Persis/Exact Match) tanpa embel-embel satuan. Misal jika jawaban adalah 50 cm, maka tulis kuncinya: 50. Berikan instruksi di naskah PDF ujian agar siswa cukup menjawab angkanya saja tanpa mengetik satuan. Jika siswa menambahkan spasi/kata lain, akan dianggap salah.
  • Uraian: Kosongkan saja. Sistem TIDAK menilai soal uraian secara otomatis. Anda wajib mengunduh rekap file Excel di akhir ujian untuk membaca hasil uraian dan memberi nilai manual.

2. Keamanan Anti-Hacker (Enkripsi Lapis Ganda)

Aplikasi ini dilengkapi Sistem Enkripsi 2 Lapis berstandar militer, sehingga MUSTAHIL bagi siswa untuk mencuri soal sebelum waktunya.

  • Gembok Pertama (Token): Berikan Token ini bebas kapan saja (misal H-1). Token ini HANYA bisa membuka sampul depan (Informasi Mapel) agar siswa bisa mengisi nama mereka. File PDF soal masih berupa huruf acak yang tidak bisa dibaca.
  • Gembok Kedua (PIN Pengawas): PIN ini HANYA boleh diucapkan secara lisan/ditulis di papan tulis oleh Pengawas ruangan tepat saat bel ujian berbunyi. Hanya dengan PIN inilah file PDF soal terbuka dan ujian dimulai.

3. Tahap Pembuatan Soal & Kunci Jawaban

  • Siapkan soal ujian Anda dalam format PDF.
  • Klik tombol + Buat Ujian Baru di Beranda.
  • Isi identitas ujian, termasuk Token Buka File dan PIN Mulai Ujian.
  • Susun kunci jawaban dan atur Poin Benar (+) dan Poin Salah (-). Poin salah sangat berguna untuk soal tipe olimpiade (Tulis -1 jika ingin jawaban salah dikurangi nilainya).
  • Klik Buat File. Aplikasi akan mengunci PDF Anda dan mengunduh file berekstensi .enc.

4. Cara Membagikan Soal via Google Drive (Sangat Disarankan)

Agar tidak membebani memori HP siswa dan server sekolah, Anda disarankan menggunakan Google Drive. Berikut langkahnya:

  1. Buka Google Drive Anda, lalu klik Baru (New) -> Upload File. Pilih file .enc yang baru saja dibuat.
  2. Setelah ter-upload, klik kanan pada file tersebut dan pilih Bagikan (Share).
  3. Pada bagian Akses Umum (General Access), ubah status dari Dibatasi (Restricted) menjadi Siapa saja yang memiliki link (Anyone with the link).
  4. Pastikan peran di sebelah kanannya adalah Pelihat (Viewer).
  5. Klik tombol Salin link (Copy link), lalu klik Selesai.
  6. Bagikan link tersebut ke grup WhatsApp siswa beserta Token Buka File.
  7. Tidak ada jaminan aplikasi dapat digunakan/lancar untuk semua jenis HP Android.

5. Cara Membagikan Soal via Whatsapp atau yang lain

Anda bis mengirim soal enc via whatssap atau yang lain yang dapat diunduh oleh siswa:

  1. Setelah siswa mendownload, aplikasi dibuka.
  2. Pilih tombol cari file di HP.
  3. Cari file yang diunduh tadi dan klik file tersebut.
  4. Masukkan Token yang dikirimkan guru.
  5. Jika benar, maka detil soal akan terbuka.
  6. Masukkan PIN rilis soal untuk memulai mengerjakan soal.
  7. Tidak ada jaminan aplikasi dapat digunakan/lancar untuk semua jenis HP Android.

6. Pengumpulan Ujian (Server)

  • Aplikasi siswa telah dilengkapi fitur Kirim Ulang Otomatis (Auto-Retry). Jika sinyal putus atau server penuh saat mengumpulkan, aplikasi akan mencoba mengirim ulang secara otomatis di latar belakang sebanyak 3x.
  • TIPS PENGAWAS: Hindari memberikan instruksi pengumpulan serentak dengan aba-aba hitung mundur (Misal: "Semuanya klik Selesai dalam 3, 2, 1!"). Hal ini dapat menyebabkan antrean data yang terlalu menumpuk. Biarkan siswa menekan tombol "Selesai" secara natural saat mereka sudah yakin.
  • Tidak ada jaminan aplikasi dan server selalu dalam keadaan lancar.
